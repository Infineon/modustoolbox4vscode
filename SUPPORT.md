# Support

This [repository](https://github.com/Infineon/modustoolbox4vscode) provides public issue tracking and approved documentation for the
Infineon ModusToolbox for VS Code extension. The extension implementation is
maintained privately and is not included here.

## Report a bug or request a feature

Search existing issues before opening a new report. Use the Bug report or Feature
request form in the repository's [Issues tab](https://github.com/Infineon/modustoolbox4vscode/issues). For documentation problems, use the
Bug report form and identify the affected page and the expected correction.

For questions about using the extension or understanding its documentation, use
the Question form. Questions are public; security reports must use the private
route described in the [security policy](SECURITY.md).

For bugs, include the extension version, VS Code version, operating system,
ModusToolbox version, relevant board/device, reproduction steps, and expected and
actual behavior. Include only the minimum sanitized diagnostics needed to explain
the problem. You do not need to upload your application to submit a report.

## Support scope

Reports about extension installation, project creation, tool integration, editor
workflows, and extension documentation belong here. General application programming,
hardware design, and unrelated tools may require another support channel. For
broader ModusToolbox questions, consult the
[Infineon ModusToolbox product page](https://www.infineon.com/modustoolbox).

Maintainers may request additional information, identify duplicates, or direct a
report to a more appropriate channel. An issue submission does not guarantee a fix
or a release date. Do not post internal tracker links or confidential development
discussions in public follow-ups.

## Protect sensitive information

Issues, comments, and attachments are public. Do not post passwords, access tokens,
private keys, proprietary source code, customer information, internal URLs, or
unreviewed logs and screenshots. Check diagnostics for usernames, local paths,
device identifiers, and other sensitive details before uploading them.

For suspected vulnerabilities, follow the [security policy](SECURITY.md).
Do not include vulnerability details in a public issue.

## Contributions

Bug reports and feature requests are welcome. Pull requests are not accepted at
this stage. See the [contribution policy](README.md#contributing).
