# Infineon ModusToolbox for VS Code Support

This [repository](https://github.com/Infineon/modustoolbox4vscode) is the public support and documentation home for the Infineon
ModusToolbox for VS Code extension. Use it to report bugs, request features, ask
usage questions, and suggest documentation corrections.

The extension implementation is maintained privately. This repository does not
contain the implementation source and cannot be used to build the extension.

## Install the extension

Install [Infineon ModusToolbox for VS Code from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=InfineonAG.modustoolbox-for-vscode).
See the Marketplace listing for product features and installation requirements,
and the [ModusToolbox product page](https://www.infineon.com/modustoolbox) for
information about the wider tool suite.

## Get help or share feedback

Search existing issues before opening a new one. In this repository's [Issues tab](https://github.com/Infineon/modustoolbox4vscode/issues),
select New issue and choose Bug report, Feature request, or Question. To report a
documentation problem, use Bug report and identify the affected page.

- Read the [support guidance](SUPPORT.md) for scope and the information to include.
- Consult the [changelog](CHANGELOG.md) for user-facing release history.

## Contributing

Bug reports, feature requests, questions, and documentation corrections are welcome
through issues. Only submit information you are authorized to share publicly.

Pull requests are not accepted at this time and may be closed with a reference to
this policy. Please report suggested improvements as issues instead.

Maintainers apply approved changes to the privately maintained originals and
publish updated copies here. Any future documentation contribution process will
be announced in this section before contributions are invited.

## Security and privacy

Issues, comments, and attachments are public. Do not post credentials, proprietary
projects, customer information, internal URLs, or unreviewed logs and screenshots.

For suspected vulnerabilities, follow the [security policy](SECURITY.md).
Do not include security-report details in a public issue.
